# «Машина времени. Спасаем будущее в прошлом»

Образовательная мобильная 3D-игра для учащихся 4 классов (ФГОС НОО), посвященная истории и краеведению Санкт-Петербурга (район Большая Охта).

## 📌 Основные параметры
- **Движок:** Unity 6 (6000.x LTS)
- **Рендер-пайплайн:** Universal Render Pipeline (URP) Forward
- **Целевая платформа:** Android 8.0+ (API 26–36), 100% Offline
- **Ориентация:** Строго портретная (Portrait 9:16, 1080×2400)
- **Репозиторий:** `https://github.com/DenisZakharov2/Game` (ветка `main`)

## 🎮 Ключевые механики
- Линейный сюжет из 24 квестов с путешествиями во времени (2027 ↔ 1950 гг.).
- Сборка прибора «Заря-7».
- Интерактивные учебные карточки (математика и русский язык).
- Исторический лор и краеведческие справки с первоисточниками.
- Система спутников (друзья, собака Барни, кот Жулик).
- Режим свободного исследования (Free-roam) после сюжета.

## 🚀 Запуск и сборка
1. Откройте проект в **Unity 6 (6000.x LTS)**.
2. Убедитесь, что установлены пакеты **URP**, **Input System**, **AI Navigation** и **TextMeshPro**.
3. Для запуска EditMode-тестов откройте окно `Window → General → Test Runner`.
4. Для сборки под Android выберите профиль `File → Build Profiles → Android` и нажмите **Build**.

## 📁 Структура проекта
- `Assets/_Project/Scripts/Core` — базовые менеджеры, шина событий, сохранения.
- `Assets/_Project/Scripts/Data` — сериализация JSON-данных и локализация.
- `Assets/_Project/Scripts/Gameplay` — контроллеры игрока, камеры, аудио и спутников.
- `Assets/_Project/Scripts/Education` — движок задач ФГОС и нормализатор ответов.
- `Assets/_Project/Scripts/Quests` — квестовые цепочки и трекеры.
- `Assets/_Project/Scripts/UI` — интерфейс, адаптация SafeArea и презентеры окон.
